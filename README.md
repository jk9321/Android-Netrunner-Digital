# Netrunner Digital (Null Signal Games Ruleset)

An open-source digital implementation of the card game **Android: Netrunner**, adhering to **Null Signal Games** comprehensive rules. Features solo play against the computer and pass-and-play for two people on one device; online multiplayer is planned.

## 📖 Project Documentation & Collaboration Guide

> **All developers and AI assistants (Antigravity, Claude, etc.):**
> - **Rules:** [Null Signal Games Comprehensive Rules](https://rules.nullsignal.games/)
> - **Project Status & Architecture:** Please refer to [PROJECT_STATUS.md](PROJECT_STATUS.md) for the active architecture, implementation roadmap, task checklist, and changelog. Update that document whenever features or changes are implemented.

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Run automated rules engine test suite
npm test
```
